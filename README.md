# OPC（One Person Company）

> **一人公司 · AI 原生的个人项目协作应用**  
> 帮助个人或小团队完成：**发现项目 → 发布招募 → 申请加入 → 协作执行 → 消息沟通 → AI 辅助**，面向移动端交互原型（Ant Design Mobile）。

本仓库是 **介绍资料 + 可运行代码 + 交付说明** 的 monorepo。要彻底接手，请按下方「阅读流程」顺序读文档，再动手跑代码。

**当前线上演示地址：** [http://118.145.240.56](http://118.145.240.56)  
（浏览器直接打开即可；需云安全组已放行 TCP 80。本地开发仍用 `http://localhost:5173`。）

## 项目特色


| 点             | 说明                                                                                                    |
| ------------- | ----------------------------------------------------------------------------------------------------- |
| **产品定位**      | 以「一个人也能发起/参与项目」为核心，不是传统企业管理软件，而是 **轻量 C2C 项目协作**。                                                     |
| **AI 原生（规划）** | 发布页支持「想法 → AI 整理 → 再发布」（`POST /projects/ai-draft`，**暂未实现，阶段 2 预留**）；后续有「问培风」助手（阶段 6）。                 |
| **移动优先**      | UI 按手机原型设计，底部 5 Tab：**发现 / 项目 / 发布 / 消息 / 我的**。                                                       |
| **契约驱动开发**    | 后端约 33 个 MVP 接口、统一 `{ code, message, data }`；表结构以 `One-Person-Campany/sql/` 与 `opc-server/prisma` 为准。 |
| **可演示迭代**     | 分 8 个阶段交付，每阶段结束都应能 demo，避免「全部做完再联调」。                                                                  |


**第一版 MVP 主链路（目标）：**  
发现 → 发布 → 申请 → 项目 Tab → 消息 → 我的 → 问培风 AI
