## 1. 项目是什么

**OPC（One Person Company / 一人公司）** 是面向大学生的**项目协作与组队平台**。

产品目标：帮助学生把「一个想法」变成「可招募、可协作、可沟通」的项目，并在平台内完成发现、申请、审核、执行与沟通；同时提供全局 AI 助手「**问培风**」，辅助处理待办、找项目、优化表达等高频问题。

第一版 MVP 要跑通的主链路是：

```text
发现 → 发布 → 申请 → 项目协作 → 消息 → 我的 → 问培风
```

---

## 2. 面向谁、解决什么问题

| 角色 | 典型诉求 |
|------|----------|
| 有想法的同学 | 发布项目、招募角色、审核申请、管理任务 |
| 想加入项目的同学 | 浏览发现页、收藏、申请加入、进群沟通 |
| 双方 | 站内消息、项目上下文、AI 辅助 |

要解决的核心痛点：校园组队信息分散、沟通割裂、项目推进缺少统一入口。

---

## 3. 核心功能一览

| 模块 | 能力摘要 |
|------|----------|
| 账号 | 手机号注册 / 登录，JWT 鉴权，个人资料与技能 |
| 发现 | 浏览、搜索项目列表，进入详情 |
| 发布 | 描述想法 → 确认草稿 → 发布或保存草稿 |
| 申请 | 申请加入、发布者审核通过/拒绝 |
| 项目 | 「进行中 / 待确认 / 已完成 / 已归档」；任务勾选 |
| 收藏 | 收藏 / 取消收藏 |
| 消息 | 会话列表、项目相关聊天、发送消息 |
| 我的 | 资料、申请、收藏、草稿、问培风入口 |
| 问培风 | 全局 AI 对话、历史记录、快捷问题 |

## 4. 技术形态（一句话）

前后端分离 Web 应用：

- 前端：React + TypeScript + Vite + Ant Design Mobile  
- 业务后端：Node.js + Express + Prisma + MySQL + JWT  
- AI 服务：Python + FastAPI，调用大模型（OpenAI 兼容接口）  
- 部署：Linux 云服务器 + Nginx + PM2  

问培风链路为：

```text
前端 → Express（鉴权/落库）→ Python 大模型服务 → 再回前端
```

密钥只放在服务端环境变量，不进入浏览器。

## 6. 演示与访问说明

- **线上演示网址（请优先用这个）：** [http://118.145.240.56](http://118.145.240.56)  
- **本地开发**：前端通常 `http://localhost:5173`，后端 `http://localhost:8080`  
- 外网访问依赖云安全组放行 **TCP 80**；服务器内可先 `curl -I http://127.0.0.1` 自检  
- 登录方式：**手机号 + 密码**（注册时还需昵称；密码至少 6 位）  
- 建议准备两个测试账号：发布者 / 申请人，便于演示完整闭环
