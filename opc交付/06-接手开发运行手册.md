# OPC 接手开发运行手册

> **读者：** 后续接手的开发 / 运维同学  
> **目标：** 按本文可在**本地**与**云服务器**拉起前后端与 AI，完成联调  
> **代码根目录：** 仓库中的 `One-Person-Campany/`

---

## 0. 开始前必读

1. 不要把 `.env`、API Key、数据库密码提交到 GitHub。  
2. 登录账号字段是**手机号**，不是用户名。  
3. 「申请成功」≠ 已进入「项目-进行中」；需发布者审核通过。  
4. 生产环境前端**没有** Vite 代理，必须靠 Nginx 把 `/api` 转到 8080。  

建议先读：

- [`01-项目总述.md`](./01-项目总述.md)  
- [`05-技术架构说明.md`](./05-技术架构说明.md)

## 2. 本地运行（开发机）

以下以 **Windows PowerShell** 与 **Linux/macOS bash** 对照；路径按本机调整。

### 2.1 依赖

| 软件 | 建议版本 |
|------|----------|
| Node.js | 20+ |
| npm | 随 Node |
| MySQL | 8 |
| Python | 3.10+ |

### 2.2 数据库（本地）

**Linux / macOS：**

```bash
cd One-Person-Campany
mysql -u root -p < sql/init_all.sql
```

或使用业务用户（推荐与服务器一致）：

```sql
CREATE DATABASE IF NOT EXISTS opc DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'opc'@'localhost' IDENTIFIED BY '你的密码';
GRANT ALL ON opc.* TO 'opc'@'localhost';
FLUSH PRIVILEGES;
```

```bash
mysql -u opc -p opc < sql/init_all.sql
```

**Windows：** 在「MySQL 命令行」或安装目录下执行同等导入；也可用图形工具执行 `sql/init_all.sql`（注意 `SOURCE` 相对路径，一键脚本需在 `One-Person-Campany` 目录执行）。

### 2.3 启动业务后端（opc-server）

**Windows：**

```powershell
cd One-Person-Campany\opc-server
copy .env.example .env
notepad .env
npm install
npm run prisma:generate
npm run dev
```

**Linux / macOS：**

```bash
cd One-Person-Campany/opc-server
cp .env.example .env
nano .env
npm install
npm run prisma:generate
npm run dev
```

`.env` 最小配置：

```env
PORT=8080
DATABASE_URL="mysql://opc:你的密码@localhost:3306/opc"
JWT_SECRET="dev-secret-change-me"
AI_SERVICE_URL="http://127.0.0.1:8000"
```

验证：

```bash
curl http://127.0.0.1:8080/api/health
```

生产构建启动（不用 `dev` 时）：

```bash
npm run build
node dist/index.js
```

### 2.4 启动 AI 服务（opc-aiservices）

**Linux / macOS / Git Bash：**

```bash
cd One-Person-Campany/opc-aiservices
python3 -m venv .venv
source .venv/bin/activate          # Windows: .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
cp .env.example .env
# 编辑 OPENAI_API_KEY 等
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

**Windows PowerShell：**

```powershell
cd One-Person-Campany\opc-aiservices
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
copy .env.example .env
# 编辑 .env
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

验证：

```bash
curl http://127.0.0.1:8000/health
```

### 2.5 启动前端（opc-web）

```bash
cd One-Person-Campany/opc-web
npm install
npm run dev
```

浏览器打开：`http://localhost:5173`  

Vite 已将 `/api` 代理到 `http://localhost:8080`，一般**不必**改前端 baseURL。

### 2.6 本地推荐启动顺序

```text
1) MySQL
2) opc-aiservices :8000
3) opc-server :8080
4) opc-web :5173
```

### 2.7 本地常用命令速查

| 目的 | 命令 |
|------|------|
| 后端热更新开发 | `cd opc-server && npm run dev` |
| 后端类型检查 | `cd opc-server && npx tsc --noEmit` |
| 前端开发 | `cd opc-web && npm run dev` |
| 前端生产构建 | `cd opc-web && npm run build` |
| Prisma Client | `cd opc-server && npm run prisma:generate` |
| AI 热重载 | `uvicorn main:app --reload --host 127.0.0.1 --port 8000` |

## 3. 云服务器运行（Ubuntu + PM2 + Nginx）

以下默认代码在：`/root/LiZihao/OPC/One-Person-Campany`（按实际路径替换）。

### 3.1 SSH 登录

使用 MobaXterm / 终端：

```text
Host: 公网IP
Port: 22
User: root（或分配账号）
```

### 3.2 查看进程是否在跑

```bash
pm2 status
systemctl status mysql --no-pager
systemctl status nginx --no-pager

curl http://127.0.0.1:8080/api/health
curl http://127.0.0.1:8000/health
curl http://127.0.0.1/api/health
curl -I http://127.0.0.1
```

### 3.3 启动 / 重启 MySQL

```bash
systemctl start mysql
systemctl enable mysql
systemctl status mysql
```

### 3.4 启动 / 重启 Express

```bash
cd /root/LiZihao/OPC/One-Person-Campany/opc-server
# 确认 .env 中 DATABASE_URL 使用 opc 用户，不是系统 root 密码登录方式
npm run build
pm2 delete opc-server 2>/dev/null
pm2 start dist/index.js --name opc-server --cwd /root/LiZihao/OPC/One-Person-Campany/opc-server
pm2 restart opc-server   # 已存在时
pm2 logs opc-server --lines 50
```

### 3.5 启动 / 重启 Python AI

```bash
pm2 delete opc-ai 2>/dev/null

pm2 start /root/LiZihao/OPC/One-Person-Campany/opc-aiservices/.venv/bin/uvicorn \
  --name opc-ai \
  --interpreter none \
  --cwd /root/LiZihao/OPC/One-Person-Campany/opc-aiservices \
  -- main:app --host 127.0.0.1 --port 8000

pm2 restart opc-ai
curl http://127.0.0.1:8000/health
```

> 若出现 `SyntaxError: Invalid or unexpected token` 且指向 uvicorn 文件：  
> 说明 PM2 用 Node 在跑 Python，必须加 `--interpreter none`。

### 3.6 前端构建与 Nginx 重载

```bash
cd /root/LiZihao/OPC/One-Person-Campany/opc-web
npm install
npm run build
chmod -R 755 dist
# 若站点 root 在 /root 下，还需保证路径上各层目录 others 可执行，见部署文档
nginx -t
systemctl reload nginx
```

### 3.7 PM2 开机自启

```bash
pm2 save
pm2 startup
# 执行其输出的 systemctl enable 命令
pm2 status
```

### 3.8 服务器日常运维命令

| 目的 | 命令 |
|------|------|
| 看状态 | `pm2 status` |
| 看后端日志 | `pm2 logs opc-server --lines 100` |
| 看 AI 日志 | `pm2 logs opc-ai --lines 100` |
| 重启全部应用进程 | `pm2 restart all` |
| Nginx 错误日志 | `tail -50 /var/log/nginx/error.log` |
| 拉代码 | `cd /root/LiZihao/OPC && git pull origin main` |

## 4. 联调自检清单

```bash
# 健康检查

curl http://127.0.0.1:8000/health
```

### 4.2 页面

1. 能打开前端  
2. 注册登录成功  
3. 发布项目后发现页可见  
4. 第二账号申请 →「待确认」有记录  
5. 审核通过 →「进行中」出现

7. 问培风有真实回复（非长期离线提示条）

## 5. 常见问题（接手高频）

| 问题 | 处理 |
|------|------|
| `Access denied for user 'root'@'localhost'` | `.env` 改用 `opc` 用户；勿用 socket 鉴权的 root 密码串硬连 |
| `/projects/mine` 500 | 更新到含 BigInt 序列化修复的版本并重启 opc-server |
| 申请成功但进行中为 0 | 正常；看「待确认」，等审核通过 |
| 问培风一直 Mock/离线 | 查 AI 进程、Key、`AI_SERVICE_URL`，`pm2 logs opc-ai` |
| 外网打不开 | 安全组放行 80；服务器内先 `curl -I http://127.0.0.1` |
| Nginx 500 Permission denied | `chmod` 路径或改用 `/var/www/opc` |
| Windows `curl` 异常 | 用 `curl.exe` 或 Postman / Invoke-RestMethod |

---

## 6. 开发约定（减少冲突）

- 前端接口封装放 `opc-web/src/api/`  
- 后端新路由优先独立文件，再在 `routes/index.ts` **一行挂载**  
- 改表：同步 `sql/` + `prisma/schema.prisma`  
- 提交前尽量本地跑通：后端 `tsc`、前端关键页面手测  
- 密钥只放服务器/本机 `.env`，交付文档只写占位符
