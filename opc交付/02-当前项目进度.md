## 1. 总体完成度

| 维度 | 状态 | 说明 |
|------|------|------|
| MVP 主链路 | **基本完成** | 发现 → 发布 → 申请 → 项目 → 消息 → 我的 → 问培风可演示 |

## 4. 已修复的重要问题（近期）

| 问题 | 处理 |
|------|------|
| 发布页只本地预览、不调接口 | 已接通 `createProject` / `updateProject` |
| `/projects/mine` 返回 500（BigInt JSON） | 已显式序列化字段 |
| 申请成功却以为「项目为 0」 | 明确：通过前在「待确认」；文案与列表已加强 |
| 云部署 Nginx 读 `/root` 权限 | 需 `chmod` 或改到 `/var/www` |
| 数据库用 `root` 密码登录失败 | 应使用业务用户 `opc` 写入 `DATABASE_URL` |
