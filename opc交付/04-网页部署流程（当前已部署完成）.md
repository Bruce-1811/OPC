# OPC 网页部署流程（云服务器）

> 适用：Ubuntu 类 Linux 云主机 + Nginx + PM2  
> 目标：外网通过 `http://公网IP` 访问 OPC  
> 示例公网 IP（以实际为准）：`118.145.240.56`

---

## 1. 部署架构

```text
浏览器
  └─ http://公网IP:80
        Nginx
          ├─ /          → 前端静态文件（opc-web/dist）
          └─ /api/      → 反代 Express :8080
                Express
                  ├─ MySQL :3306
                  └─ Python AI :8000（仅本机）
```

**安全建议：** 对外只放行 **22（SSH）**、**80（HTTP）**。  
不要对公网开放 3306、8000、8080。

## 4. 配置 MySQL

### 4.1 创建库与用户

```bash
sudo mysql
```

```sql
CREATE DATABASE IF NOT EXISTS opc
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_unicode_ci;

CREATE USER IF NOT EXISTS 'opc'@'localhost' IDENTIFIED BY '你的密码';
GRANT ALL PRIVILEGES ON opc.* TO 'opc'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

### 4.2 导入表结构

必须在 `One-Person-Campany` 目录下执行（脚本含相对 `SOURCE`）：

```bash
cd /root/LiZihao/OPC/One-Person-Campany
mysql -u opc -p opc < sql/init_all.sql
mysql -u opc -p -e "USE opc; SHOW TABLES;"
```

## 5. 部署 Python AI（opc-aiservices）

```bash
cd /root/LiZihao/OPC/One-Person-Campany/opc-aiservices
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

cp -n .env.example .env
nano .env
```

`.env` 示例：

```env
OPENAI_API_KEY=你的密钥
OPENAI_BASE_URL=https://ws-6juch5algsm3eel1.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
OPENAI_MODEL=qwen-turbo
```

启动（注意：`--interpreter none`，否则 PM2 会当 Node 跑）：

```bash
deactivate
pm2 delete opc-ai 2>/dev/null

pm2 start /root/LiZihao/OPC/One-Person-Campany/opc-aiservices/.venv/bin/uvicorn \
  --name opc-ai \
  --interpreter none \
  --cwd /root/LiZihao/OPC/One-Person-Campany/opc-aiservices \
  -- main:app --host 127.0.0.1 --port 8000

curl http://127.0.0.1:8000/health
# 期望含 "status":"ok" 且 "hasApiKey":true
```

## 6. 部署 Express（opc-server）

```bash
cd /root/LiZihao/OPC/One-Person-Campany/opc-server
cp -n .env.example .env
nano .env
```

关键配置：

```env
PORT=8080
DATABASE_URL="mysql://opc:你的密码@localhost:3306/opc"
JWT_SECRET="换成长随机串"
AI_SERVICE_URL="http://127.0.0.1:8000"
```

注意：

- **不要用** Ubuntu 的 `root` 去做密码连接（易 1698 Access denied）  
- 密码含 `! @ # /` 等时，`DATABASE_URL` 中需 URL 编码（如 `!` → `%21`）

```bash
npm install
npm run prisma:generate
npm run build

pm2 delete opc-server 2>/dev/null
pm2 start dist/index.js --name opc-server --cwd /root/LiZihao/OPC/One-Person-Campany/opc-server

curl http://127.0.0.1:8080/api/health
# 期望 {"code":0,"message":"ok",...}
```

## 7. 构建前端 + Nginx

### 7.1 构建

```bash
cd /root/LiZihao/OPC/One-Person-Campany/opc-web
npm install
npm run build
```

产物目录：`opc-web/dist`

### 7.2 Nginx 配置

```bash
nano /etc/nginx/sites-available/opc
```

```nginx
server {
    listen 80;
    server_name 你的公网IP;

    root /root/LiZihao/OPC/One-Person-Campany/opc-web/dist;
    index index.html;

    location /api/ {
        proxy_pass http://127.0.0.1:8080/api/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

启用：

```bash
ln -sf /etc/nginx/sites-available/opc /etc/nginx/sites-enabled/opc
rm -f /etc/nginx/sites-enabled/default
nginx -t
systemctl reload nginx
```

### 7.3 权限（若 500 Permission denied）

代码在 `/root` 下时，Nginx 用户可能读不到：

```bash
chmod 755 /root
chmod 755 /root/LiZihao
chmod 755 /root/LiZihao/OPC
chmod 755 /root/LiZihao/OPC/One-Person-Campany
chmod 755 /root/LiZihao/OPC/One-Person-Campany/opc-web
chmod -R 755 /root/LiZihao/OPC/One-Person-Campany/opc-web/dist
systemctl reload nginx
```

更稳妥：把 `dist` 拷到 `/var/www/opc`，并把 Nginx `root` 改过去。

### 7.4 验证

```bash

```

浏览器：`http://公网IP`

## 9. 云安全组（公网能打开的关键）

仅 SSH 权限时，需云账号所有者在控制台操作：

- 方向：入站  
- 协议：TCP  
- 端口：80  
- 来源：`0.0.0.0/0`  
- 策略：允许  

服务器内 `curl 127.0.0.1` 正常、外网超时 → 几乎都是安全组未放行 80。

可选本机防火墙：

```bash
ufw status
ufw allow 80/tcp
ufw reload
```

## 11. 故障速查

| 现象 | 排查 |
|------|------|
| 外网超时 | 安全组 80、ufw、Nginx 是否 listen 0.0.0.0:80 |
| 页面 500 | `tail -30 /var/log/nginx/error.log`（常见 Permission denied） |
| 注册 500 | `pm2 logs opc-server`；检查 `DATABASE_URL` 是否为 `opc` 用户 |
| 问培风离线 | `curl :8000/health`；`AI_SERVICE_URL`；API Key |
| `/api` 不通 | Nginx `location /api/`；`curl http://127.0.0.1/api/health` |

更完整的本地 + 服务器命令见：[`06-接手开发运行手册.md`](./06-接手开发运行手册.md)
